## 📝 รายละเอียดแต่ละจุด

### 🏞️ อุทยานแห่งชาติออบขาน (Ob Khan National Park)

โกรกธารน้ำแม่ขาน หน้าผาหินสูงชัน น้ำใส เดินป่าริมธาร  
🕐 เปิด 08:00-17:00 | 💰 100/คน (เด็ก 50)  
📍 [Google Maps](https://maps.google.com/?q=Ob+Khan+National+Park+Chiang+Mai)

### 🪵 บ้านถวาย (Baan Tawai)

หมู่บ้านหัตถกรรมแกะสลักไม้ใหญ่ที่สุดในภาคเหนือ  
ร้านค้า 100+ ร้าน ชมช่างฝีมือแกะสลักไม้จริง  
🕐 ~09:00-17:00 | 💰 ฟรี  
📍 [Google Maps](https://maps.google.com/?q=Baan+Tawai+Chiang+Mai)

### 🌲 ห้วยฮ่องไคร้ (Huai Hong Khrai Royal Development Study Center)

โครงการหลวงในพระราชดำริ ร.9 — ป่าฟื้นฟู ฝายชะลอน้ำ สัตว์ป่า เส้นทางศึกษาธรรมชาติ  
🕐 08:30-16:30 | 💰 ฟรี  
📍 [Google Maps](https://maps.google.com/?q=Huai+Hong+Khrai+Chiang+Mai)

### 🌊 เขื่อนแม่กวงอุดมธารา (Mae Kuang Dam)

อ่างเก็บน้ำใหญ่ วิวภูเขา จุดถ่ายรูปยอดนิยม แวะก่อนเข้าสวนทวีชล  
🕐 ทั้งวัน | 💰 ฟรี  
📍 [Google Maps](https://maps.google.com/?q=Mae+Kuang+Dam+Chiang+Mai)

### 🎯 สวนทวีชล (Suan Taweechon / Tweechol Botanical Garden)

สวนพฤกษศาสตร์ขนาดใหญ่ รีสอร์ท สวนสัตว์เล็ก เขาวงกต สระว่ายน้ำ ร้านอาหาร  
📍 [Google Maps](https://maps.google.com/?q=Tweechol+Botanical+Garden+Chiang+Mai)
